# ГЭТ PDF → ГЭТ System: локальный контракт статуса v1

**Статус:** реализация в черновом PR, **не подтверждена Windows-сборкой**,
и не является подключением к действующему API ГЭТ System.

В `%PROGRAMDATA%\\GET-PDF\\policy.json` администратор может включить:
```json
{
  "Version": 1,
  "ExportGetSystemStatus": true
}
```

По умолчанию экспорт **выключен**. При включении, во время открытия/
закрытия PDF-вкладок и окон, приложение атомарно обновляет файл:
`%LOCALAPPDATA%\\GET-PDF\\integration\\getpdf-status.v1.json`.

Схема `get-system.pdf.status.v1`, поля:
```json
{
  "Schema": "get-system.pdf.status.v1",
  "Product": "GET-PDF",
  "ApplicationVersion": "0.1.0",
  "GeneratedUtc": "2026-10-20T12:00:00+00:00",
  "OpenWindows": 1,
  "OpenDocuments": 2,
  "PrintingAllowed": true,
  "OfflineOnly": true
}
```

Поле `GeneratedUtc` имеет временную зону UTC, счётчики ограничены и
не содержат идентификаторов пользователей, компьютеров, IP, путей PDF,
названий файлов, результатов поиска, текста или содержимого документов.
ГЭТ PDF **не** отправляет запросы в сеть и не требует наличия GET-system.

Агент GET-system сможет читать этот локальный файл только после
утверждения ИТ-службой соответствующей схемы и Windows ACL. Обмен
управляющими командами, загрузка документов, аудит/авторизация, версии
API GET-system и обратные вызовы — отдельный будущий этап. Нельзя считать
этот локальный экспорт авторизованной серверной интеграцией.

Тесты `PdfGetSystemStatusTests` добавлены, **не запускались**.
