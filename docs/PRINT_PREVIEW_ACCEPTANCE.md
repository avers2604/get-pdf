# Предпросмотр печати ГЭТ PDF

Новая промежуточная форма `PdfPrintPreviewWindow` показывает **фактическое содержимое `PdfPagePrintPaginator`** вместе с рамками, текстовыми заметками и штампами; подготовленные PNG не публикуются за пределы выделенного scratch. Диспетчер PDF-заданий держит одно задание до закрытия предпросмотра и синхронной передачи Windows PrintDocument. Отмена в предпросмотре **не** передаёт документ принтеру; статус не должен сообщать об успехе.

Перед предпросмотром пользователь может выбрать A3/A4, ориентацию, дуплекс и количество копий. Настройки сверяются с объявленными возможностями драйвера Windows и сохраняются только локально. Неподдерживаемые сочетания отклоняются, а не молча игнорируются. Это не означает, что реальные МФУ корректно выполняют заявленные возможности.

Оставлено на аппаратную проверку: PDF диапазоны, A4/A3, ориентация, 200/300/600 DPI фактического принтера, дуплекс (параметры драйвера), копии, очередь Windows, отмена во время спулинга, краевые поля и качество мелкого текста. Векторная печать пока не реализована: WPF использует растровый page spool, это отражено в `PdfPagePrintPaginator`.

Без пройденного Windows gate и реального принтера **не** называть эту реализацию проверенной.
