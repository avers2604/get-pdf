# GD-02 — PDF, изображения, TXT/MD/CSV в общей вкладке (черновой инкремент)

## Фактические изменения
- В `GetDocument.Desktop` появился `PDFtoImage` 5.4.0 — MIT;
  в транзитивных зависимостях отдельные native PDFium/SkiaSharp для Windows и Linux.
  В старом WPF GetPdf PDFium не менялся; новый пакет добавлен только для новой Avalonia оболочки.
- Один PDF рендерится постранично, PNG отображается Avalonia Bitmap в той же вкладке.
  Кнопки вперёд/назад; максимальное измерение растра 1440 px;
  лимит на исходный PDF 128 МиБ и до 1000 страниц.
- PDFium сериализован единым `SemaphoreSlim`. Пользовательский ввод не блокируется
  во время рендеринга, поздние результаты устаревших операций игнорируются.
- Изображения показываются через Avalonia Bitmap.DecodeToWidth(1400) с ограничением
  размера исходного файла; многостраничные TIFF и редактирование ещё не готовы.
- TXT, MD, CSV имеют текстовый просмотр, до 2 МиБ и без редактирования.
- Для DOC/XLS/PPT и OOXML пока честное предупреждение вместо демонстрации
  несуществующей совместимости.
- Добавлены изолированные MSTest для `PdfPreviewPlan` в платформенно-независимом Core.

## Ограничения
- Это начальный **просмотр**, не готовый полноценный PDF редактор. Печать, формы,
  OCR, выделение текста и подписи остаются в прежнем WPF приложении,
  до изоляции старых подсистем в общие адаптеры.
- Не импортировать и не сохранять офисные файлы до отдельной лаборатории.
- Проверки PDF с вредоносными вложениями, очень большими страницами, нарушенной
  структурой, авариями native PDFium / image decode нужно провести в
  изолированном worker-процессе: данный прототип пока рендерит нативный PDFium
  внутри процесса программы и НЕ ГОДИТСЯ для производственных рабочих мест.
- Из-за отсутствия dotnet SDK в доступной среде НЕ ПРОВЕДЕНЫ
  компиляция, `dotnet test` или UI/печать на Windows/Linux.
- Требуется отдельная проверка совместимости native dependencies на
  Astra Linux, Альт и РЕД ОС; для сетевых SMB/PDF — тесты недоступного файла.
- Не добавлены GitHub Actions. PR остаётся draft, не сливать в main.

## Проверка на локальных Windows/Linux рабочих станциях
```sh
dotnet restore GetDocument.slnx
dotnet build GetDocument.slnx -c Release --no-restore
dotnet test tests/GetDocument.Core.Tests/GetDocument.Core.Tests.csproj -c Release
dotnet run --project src/GetDocument.Desktop/GetDocument.Desktop.csproj
```
UI: открыть PDF и перейти на вторую страницу; одновременно открыть PNG, TXT,
DOCX и XSLX во вкладках; закрыть вкладку во время рендеринга; проверить,
что не происходит внешних запросов и не запускаются новые окна;
проверить потерю подключения SMB и повреждённые файлы.
