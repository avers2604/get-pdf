# GD-14: подтверждённая привязка вкладки ГЭТ Документ к GUP-2

**Дата:** 25.10.2026. **Статус:** Draft, локальные .NET/Avalonia/Windows/Linux испытания **не проведены**.

## Как сотрудник пользуется

1. В GUP-2 откройте карточку требуемого документа и скачайте DOCX/XLSX через обычную ссылку с авторизацией/проверкой SHA.
2. В «ГЭТ Документ» откройте файл в общей панели вкладок. Выберите **именно эту** вкладку.
3. В карточке GUP-2 нажмите «Привязать вкладку ГЭТ Документ», скопируйте одноразовый код на 5 минут.
4. В настольном приложении нажмите «Связать вкладку с GUP-2», вставьте код, выберите проверку. Приложение вычислит SHA-256 локального файла, сопоставит с закреплённой на сервере текущей рабочей копией и получит UUID/версию/рег. номер. В верхней вкладке появится отметка GUP-2 с номером карточки.
5. Если файл изменится или вкладка закроется, привязка удаляется. После изменений/сохранения новой редакции потребуется сверить версию заново. Привязка **не даёт** права сохранять в GUP-2: для этого используется отдельный код отправки, ACL, AV, CAS.

## Политика ИТ-службы

В корпоративном локальном `policy.json`, который устанавливается и редактируется только администратором, активировать лишь после серверной проверки:

```json
{
  "Version": 1,
  "AllowGup2TabBinding": true,
  "Gup2DocumentsUrl": "https://gup2.example.internal/documents/"
}
```

Путь Windows: `%ProgramData%\GET-Document\policy.json`. Linux: `/etc/get-document/policy.json`. Установщик должен гарантировать admin/root-only запись. При неправильном/отсутствующем файле политика выключена. Отдельный серверный флаг `GETDOCUMENT_TAB_BIND_ENABLED=1` необходим; его включение не активирует офисную отправку. `gup2.example.internal` — **пример**.

Клиент по одному POST передаёт только **43-символьный код в заголовке** и SHA-256 текущего DOCX/XLSX. Код и UUID не пишутся в файл, логи и командную строку. Нет default credentials, cookie, HTTP redirect, подмены TLS validation и передачи офисного содержимого. Ответ ограничен по размеру и проверяется полностью, включая формат SHA, UUID и расширение. Привязка действует только в памяти процесса.

## Не выполнено

- Подтверждение работоспособности на Windows 10/11, Linux, Astra/ALT/РЕД.
- `dotnet restore`, `dotnet test tests/GetDocument.Core.Tests/GetDocument.Core.Tests.csproj -c Release`, `dotnet build src/GetDocument.Desktop/GetDocument.Desktop.csproj -c Release`.
- E2E с GUP-2/PostgreSQL, корпоративным TLS/PKI, реальной рабочей копией, блокировкой пользователя/ДСП, длинными именами и изменением файла во время передачи, двумя одновременно открытыми файлами с одинаковым названием.
- Не реализованы автоматический SSO и бесшовное открытие через протокол ОС, live-соединение с GUP-2 для отслеживания изменения серверной версии, совместное редактирование WOPI, автосохранение по Ctrl+S в GUP-2.
- Физический WORM-архив старых рабочих копий находится в отдельном блоке разработки; серверная операция `check_office_history` только обнаруживает отсутствие/порчу файлов.
