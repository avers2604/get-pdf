# GD-09 — Матрица проверки полнофункциональных Office-движков

Это **план испытаний**, а не оценки пройденных тестов. Значения «Не проверено»
означают, что утверждения о функциональности и совместимости делать нельзя.

| Критерий | LibreOffice локальный (UNO/SDK) | Collabora Online (WOPI) | ONLYOFFICE Docs (Docs API) |
|---|---|---|---|
| Собственный UI по брендбуку ГЭТ поверх всех команд движка | Не проверено | Не проверено | Не проверено |
| DOCX: стили, колонтитулы, таблицы, комментарии, track changes | Не проверено | Не проверено | Не проверено |
| XLSX: формулы, сводные таблицы, графики, условное форматирование | Не проверено | Не проверено | Не проверено |
| PPTX: темы, переходы, фигуры, изображения, заметки | Не проверено | Не проверено | Не проверено |
| DOC/XLS/PPT: импорт и roundtrip сохранность | Не проверено | Не проверено | Не проверено |
| Внутренний multiuser и коллизии | Требует отдельного backend | Не проверено | Не проверено |
| Изменение без копирования оригинала WORM | Контракт нужен | Контракт нужен | Контракт нужен |
| Развёртывание без интернета на собственном сервере | Не проверено | Не проверено | Не проверено |
| Корпоративная лицензия без обязательной платной подписки | Не проверено | Не проверено | Не проверено |
| Слабые Windows ПК, Linux/Astra/ALT/РЕД ОС | Не проверено | Не проверено | Не проверено |
| Печать, цветопередача, русские шрифты и DPI | Не проверено | Не проверено | Не проверено |

**Формат записи результатов:** образец файла, SHA-256, версии Office/
движка и OS, сценарий, доступный метод API, эталонный вывод в Microsoft
Office, diff до/после, CPU/RAM, время операции, скриншоты, результат
Pass/Fail/Ограничено/Не проверено, лицензия.

Критерии блокировки выбора: неприемлемая лицензия/брендинг, 
полноценный собственный UI невозможен через документированный API,
ошибки OOXML с потерей данных, нет offline режима и доверенного
server-side revision sink.

**PR #22** = ONLYOFFICE контракт; **следующий Collabora PR** =
read-only WOPI контракт. Ни один не является утверждением движка.
