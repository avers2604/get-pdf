# GD-09/GD-17 — Матрица проверки полнофункциональных Office-движков

**Решение от 26.10.2026:** Euro-Office — основной серверный движок для ГЭТ Документы (проверка ещё не пройдена). LibreOffice — автономный резерв; ONLYOFFICE и Collabora сохраняются только в качестве сравнительных/legacy адаптеров. См. [GD-17](GET_DOCUMENT_EURO_OFFICE_PRIMARY_2026-10-26.md).


Это **план испытаний**, а не оценки пройденных тестов. Значения «Не проверено»
означают, что утверждения о функциональности и совместимости делать нельзя.

| Критерий | **Euro-Office (основной, сервер)** | LibreOffice локальный (UNO/SDK) | Collabora Online (WOPI) | ONLYOFFICE Docs (Docs API) |
|---|---|---|---|---|
| Собственный UI по брендбуку ГЭТ поверх всех команд движка | Не проверено | Не проверено | Не проверено | Не проверено |
| DOCX: стили, колонтитулы, таблицы, комментарии, track changes | Не проверено | Не проверено | Не проверено | Не проверено |
| XLSX: формулы, сводные таблицы, графики, условное форматирование | Не проверено | Не проверено | Не проверено | Не проверено |
| PPTX: темы, переходы, фигуры, изображения, заметки | Не проверено | Не проверено | Не проверено | Не проверено |
| DOC/XLS/PPT: импорт и roundtrip сохранность | Не проверено | Не проверено | Не проверено | Не проверено |

**Формат записи результатов:** образец файла, SHA-256, версии Office/
движка и OS, сценарий, доступный метод API, эталонный вывод в Microsoft
Office, diff до/после, CPU/RAM, время операции, скриншоты, результат
Pass/Fail/Ограничено/Не проверено, лицензия.

Критерии блокировки выбора: неприемлемая лицензия/брендинг, 
полноценный собственный UI невозможен через документированный API,
ошибки OOXML с потерей данных, нет offline режима и доверенного
server-side revision sink.

**GD-17** = Euro-Office как основной кандидат и прототип серверной Docs API конфигурации (не подключён к production broker). **PR #22** = ONLYOFFICE контракт; **следующий Collabora PR** =
read-only WOPI контракт. Ни один не является утверждением движка.
