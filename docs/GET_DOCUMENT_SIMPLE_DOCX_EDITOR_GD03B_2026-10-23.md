# GD-03B — безопасное текстовое редактирование простых DOCX

## Что реализовано
- `SimpleDocxTextService` в кроссплатформенном `GetDocument.Office`, используя уже
  существующую зависимость `DocumentFormat.OpenXml 3.5.1`.
- В одной вкладке Avalonia разрешено редактирование только простых DOCX,
  содержащих обычные `w:p` → `w:r` → `w:t` без форматирования.
- Поддержаны кириллица, пустые строки, пробелы, создание новой редакции
  и открытие сохранённой копии в соседней вкладке.
- Сложные DOCX (таблицы, стили, примечания, секции, изображения, колонтитулы)
  явно отклоняются: для них планируется полнофункциональный движок
  LibreOffice/ProEdit после лаборатории, никакой тихой потери вёрстки.
- Источник не меняется. Отдельная копия создаётся через новый временный файл
  в папке назначения и `File.Move` без перезаписи. Применён SHA-256
  для предотвращения сохранения редакции от изменившегося источника.
- Закрытие вкладки или целого окна при несохранённых правках блокируется,
  пока сотрудник не сохранит новую копию или не отменит изменения.

## Ограничения и следующие шаги
- Не полноценный Word. Нет rich-text, таблиц, подписей, WORM lifecycle,
  совместного редактирования или интеграции GUP-2.
- Оригинал не модифицируется, но это не заменяет серверные ACL/аудит;
  SMB файловый сервер остаётся источником правды.
- При отказе сети, конфликте имени или изменении оригинала сохранение
  прерывается с сообщением, новая редакция не подменяет оригинал.
- Кнопка печати всё ещё заглушка; текущий рабочий WPF PDF не менялся.
- UI меняет обработчик для .docx, другие форматы прежние.

## Тесты и статус
Добавлены 6 MSTest: простое редактирование с реальным OOXML,
пустые строки и пробелы, запрет сложного документа,
изменение источника, запрет overwrite, несовпадающее расширение.
Тесты записаны до кода, но в среде нет dotnet CLI: RED/GREEN и сборка
НЕ проверены, не утверждать прохождение. Не включать GitHub Actions.

На Windows и Linux:
```sh
dotnet restore GetDocument.slnx
dotnet build GetDocument.slnx -c Release --no-restore
dotnet test tests/GetDocument.Office.Tests/GetDocument.Office.Tests.csproj -c Release
dotnet test tests/GetDocument.Core.Tests/GetDocument.Core.Tests.csproj -c Release
```
Ручные тесты: кириллица/многострочный текст, `Сохранить редакцию`,
отказ сложному DOCX, отсутствие перезаписи, отказ SMB, предупреждение
при закрытии с несохранённым текстом, разные документы в одном окне.
