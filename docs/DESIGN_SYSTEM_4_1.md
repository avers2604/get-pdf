| Решение DS 4.1 | Реализация |

| D41-05: без левой навигационной панели, печать — компактная кнопка | Шапка: знак + «ГЭТ PDF» + вкладки + «+». ## Проверено

- `dotnet build` и 181/181 MSTest на Windows 11, .NET SDK 10.0.402.
- Ручная проверка на 125 % DPI: развёрнутое окно и ширина 950 DIP; вкладки; поиск
  с подсветкой; выделение текста; редактор; пустая вкладка; диалог принтера →
  параметры → предпросмотр → отмена (виртуальный «Microsoft Print to PDF», очередь пуста).
- UI Automation видит содержимое вкладок и кнопки шапки.

## Открыто

- **Шрифт:** DS 4.1 не утвердила гарнитуру (D41-12: Echoes Sans / Verdana / Futura PT).
  Используется системный Segoe UI. Замена — одна строка в `PdfTabbedWindow` и шаблонах после решения по лицензии.
- **Тёмная тема** (`#151B33`) и проверка при масштабе 200 % / с экранным диктором не выполнялись.
- Диалоги, создаваемые в коде (сравнение, формы, подписи и др.), получают стили
  кнопок и полей автоматически, но их компоновка не перерабатывалась.
- Счётчик масштаба «100 %», показанный на макете, отсутствует: приложение пока не публикует текущий процент масштаба.
