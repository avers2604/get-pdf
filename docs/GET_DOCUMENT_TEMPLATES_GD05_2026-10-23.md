# ГЭТ Документ — GD-05 / пилотные шаблоны (23.10.2026)

## Что добавлено
- Отдельный модуль `GetDocument.Office.Templates.CorporateTemplateService`.
- Лаунчер и шапка приложения получили кнопку «Шаблоны»; отдельная **вкладка того же окна**
  с формой реквизитов, предпросмотром и созданием настоящего DOCX.
- Три пилотных варианта: **служебная записка, акт, письмо**. Это примеры,
  **не официально утверждённые** формы ГЭТ: для итоговых бланков нужны конкретные
  образцы DOCX, правила нумерации, согласование делопроизводства и официальный логотип.
- Поля: подразделение, автор, адресат, тема, номер, дата, содержание.
- Текст собирается Scriban **7.5.1 BSD-2-Clause**, DOCX создаётся ранее
  подключённым `DocumentFormat.OpenXml 3.5.1 MIT`.
- Встроенные шаблоны заданы только строками из исходного кода;
  произвольный ScriptObject пользователя, подключение удалённых исходников,
  загрузку необработанных шаблонов с SMB и выполнение пользовательских выражений
  не поддерживаем.
- Данные обрабатываются локально. В этом блоке нет нового HTTP, сервера,
  базы данных или сохранения введённых персональных полей.
- Лимитируем длины реквизитов, управляющие символы и объём результата.
- Сначала создаётся временный DOCX в выбранной папке, затем
  `File.Move(stage, target)` **без перезаписи**. WORM и другие оригиналы не
  изменяем. Сетевые права реализуются SMB/ACL на сервере, новых ролей не даём.
- После создания документ передаётся в существующий Workspace, открывается
  в соседней вкладке. Шаблоны можно открыть повторно без создания второго таба.

## Проверяемые границы
- Генерируемая форма — **текстовый DOCX**, без официального колонтитула и
  без гарантированного соответствия канцелярским формам СПб ГУП.
- Не внедрён редактор утверждённых шаблонов, электронная подпись,
  маршрут согласования и сквозная нумерация (это отдельные бизнес-функции).
- `Scriban` используется только на предопределённых шаблонах.
- Тесты не могут заменить приёмку Word/LibreOffice на реальных документах.
- При аварии SMB создание завершается ошибкой, без тихого изменения оригинала.

## Локальные тесты
- 7 новых test methods (включая один параметризованный на 3 формы):
  корректность OOXML, кириллица и дата, недопуск перезаписи, валидация
  полей, отсутствие исполнения `{{ expressions }}` из пользовательского текста,
  многострочный контент и отказ неверному расширению.
- В контейнере нет `dotnet` CLI: `dotnet restore/build/test` **НЕ выполнялись**.
- GitHub Actions не включать. PR остаётся Draft.

Команды Windows/Linux:
```sh
dotnet restore GetDocument.slnx
dotnet build GetDocument.slnx -c Release --no-restore
dotnet test tests/GetDocument.Core.Tests/GetDocument.Core.Tests.csproj -c Release
dotnet test tests/GetDocument.Office.Tests/GetDocument.Office.Tests.csproj -c Release
```

UI-тесты: открыть «Шаблоны», проверить все 3 формы, ввести русский текст,
предпросмотр, сохранить новый DOCX, открыть в новой вкладке, запретить
перезапись существующего файла, отменить диалог, отключить SMB, повторно
открыть вкладку, проверить работу Ctrl+W и отсутствие внешнего трафика.
