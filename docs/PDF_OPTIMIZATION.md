# Lossless PDF optimization using approved qpdf

Опция редактирования «Оптимизировать PDF» использует только ИТ-утверждённый `tools/qpdf/qpdf.exe` вместе с утверждённым SHA-256 `qpdf.sha256`. Утилита не скачивается. Если qpdf отсутствует или не подтверждён, операция не выполняется. PDF с известными ограничителями структурной записи отклоняются.

Оптимизация применяет `--stream-data=compress --object-streams=generate`, без `--optimize-images` и без перекодирования JPEG. Формируется отдельная временная копия; перед публикацией проверяются структура, количество страниц, извлечённый текст и контроль qpdf. Копия публикуется только если стала меньше оригинала. Предыдущие документы не перезаписываются. Внешние действия PDF не исполняются.

Ограничение: проверка текста не удостоверяет бинарную идентичность изображений, цифровых подписей, форм и интерактивных объектов. Для подписанных или сложных интерактивных PDF операция должна быть заблокирована. Все результаты требуют отдельной лабораторной проверки на Windows, особенно документы с формами, закладками и защищённые PDF.
