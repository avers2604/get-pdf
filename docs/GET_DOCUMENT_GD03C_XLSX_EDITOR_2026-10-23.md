# ГЭТ Документ — GD-03C: простой XLSX в единой вкладке

В отдельном Draft PR реализован ограниченный редактор **текстового листа A1:J10**.
Он использует уже установленный Open XML SDK и не добавляет новых NuGet пакетов.

- Строгий отказ для рабочих книг с формулами, форматированием, дополнительными
  листами, внешними связями и сложным содержимым. Это не полноценный Excel.
- Исходник сохраняется без изменений; новая редакция публикуется в другой
  XLSX через временную копию и `File.Move` без overwrite.
- Контроль SHA-256 между открытием и записью, повторная проверка staged XLSX.
- Текст, начинающийся на `=`, хранится как `inlineStr`, а не как формула.
- Нельзя закрыть вкладку или окно без сохранения/отмены несохранённых правок.
- UI — таблица 10 × 10 в прежнем TabControl, без дополнительных окон.
- `DocumentWorkspace.BindNewRevision` расширен на XLSX с прежним ID вкладки.

## Ограничения
- Формулы, стили, таблицы с диаграммами, массивы, большие листы,
  фильтры и содержимое за J10 намеренно не поддерживаются.
- Изменение исходного файла запрещено; для снимков/версий GUP-2
  потребуется отдельный интеграционный контракт.
- Рендеринг и обработка сторонних OOXML в производственной сети требуют
  выделенного worker с лимитами памяти/времени и проверками ZIP-структуры.
- PPTX в рамках GD-03C не редактируется; следующий этап: безопасный
  текст слайда и проверка полного офисного движка.
- В доступном исполнителе нет `dotnet` SDK — компиляция,
  MSTest и UI-тесты **не запускались**.

## Локальная проверка после сборки
```
dotnet restore GetDocument.slnx
dotnet build GetDocument.slnx -c Release --no-restore
dotnet test tests/GetDocument.Core.Tests/GetDocument.Core.Tests.csproj -c Release
dotnet test tests/GetDocument.Office.Tests/GetDocument.Office.Tests.csproj -c Release
```
Проверить Windows и Linux: создание XLSX, просмотр A1:J10, ввод кириллицы,
сохранение в новый файл, отсутствие пересчёта выражения `=2+2`,
защиту от перезаписи, конфликт изменённого сетевого XLSX,
попытки открыть формулы/стили, недоступную Samba и отмену сохранения.
GitHub Actions не использовать.
