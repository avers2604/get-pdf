# ГЭТ PDF — дорожная карта согласованных улучшений (20.10.2026)

Репозиторий: `avers2604/get-pdf`. Базовое выделение: draft PR #1 (`split/pdf-only-wpf`). Эта карта отражает согласованное внедрение **всех** предложенных функций. Начальная реализация ведётся отдельно в `feature/pdf-workspace-improvements`; статические проверки не равны PASS на Windows.

## 1. Стабилизация и UI — частично реализовано

- [x] Независимые search UI, Ctrl+F, Enter/F3 без открытия редактора.
- [x] Чистая главная панель просмотра: поиск, открытие PDF, печать; расширенные функции — в редакторе.
- [x] Drag-and-drop и локальная ограниченная история недавних PDF.
- [x] Локальные закладки, полноэкранный режим F11, непрерывный/одностраничный/двухстраничный просмотр.
- [ ] Реальный tabbed host с независимыми состояниями PDF, закрытием и восстановлением вкладок (сейчас отдельные окна).
- [ ] Точное текстовое выделение мышью поверх PDF, копирование выделенного текста и ссылки внутри документа.
- [ ] PDF outline/оглавление, работа с внутренними/внешними ссылками без автоматического запуска URL.
- [ ] Нормализация адаптивной панели и полноценные keyboard/accessibility/экранные тесты.

## 2. Печать — частично реализовано

- [x] Предпросмотр реального WPF paginator перед передачей в spooler, включая разметку и штампы.
- [x] Cancel в предпросмотре не вызывает PrintDocument.
- [ ] Векторная печать или надёжный native PDF print pipeline с fallback на текущий raster spool.
- [ ] Расширенные параметры драйвера, конкретные принтеры МФУ, A3/A4, ориентация, копии/дуплекс, сохранение настроек.
- [ ] Подтверждённые тесты на физических устройствах, spooler errors, отмена, поля и читаемость мелкого текста.

## 3. Документы и PDF-инструменты — частично реализовано

- [x] Compare text layer: LCS выравнивание добавленных/удалённых/изменённых страниц, явное «сканы не проверены».
- [x] Lossless qpdf optimization только с ИТ-approved SHA-256, строгими проверками, и только отдельная копия.
- [x] Массовая нумерация страниц и независимый экспорт страниц (лимит 200 за операцию).
- [x] Копирование текста текущей страницы по явному действию пользователя.
- [ ] Настоящее выделение мышью, подробный визуальный diff, перераспределение страниц между вкладками.
- [ ] Настоящие водяные знаки с координатами/поворотом/прозрачностью и сохранением структуры PDF.
- [ ] Заполнение/сохранение AcroForm с реальной поддержкой кириллицы и пересозданием appearance; XFA не считать поддержанным.
- [ ] Криптографическая проверка ЭП/КЭП, цепочки доверия, времени подписи, CRL/OCSP с поддержкой автономных корпоративных доверенных источников. **Не выводить «подпись действительна» по /ByteRange.**
- [ ] Проверить качество исходного текстового редактора на шрифтах, кириллице, защите, формах и подписанных PDF.

## 4. Backend и безопасность — частично реализовано

- [x] Bounded PDF text comparison (1000 стр. и 2 млн символов на страницу).
- [x] LRU кеш миниатюр ограничен 12 элементами и оценкой 48 MiB.
- [x] Без сетевого сервиса/обязательных облачных API, локальные папки GET-PDF.
- [ ] Новое viewport-resolution rendering без декодирования полного исходного растра на каждое движение масштаба.
- [ ] Профилирование UI/рендера (200/500/1000 страниц), лимиты native memory, документированный memory budget.
- [ ] Изоляция обработки недоверенных PDF в отдельном процессе и безопасная обработка повреждённых PDF.
- [ ] Политика ИТ-службы по истории документов, закладкам, диагностике, паролям и очистке.
- [ ] Тесты конкурентных операций, восстановления после падения и адекватное покрытие критических веток.

## 5. Выпуск и интеграция — подготовлено, приёмка не завершена

- [x] WiX source для отдельного GetPdf MSI с новым UpgradeCode, ярлыком и Open With без изменения Windows UserChoice.
- [x] Локальный скрипт для restore/build/MSTest/publish/WiX/optional Authenticode и SHA-256 release manifest.
- [ ] Выполнение Windows gate, установка/обновление/удаление на тестовых ПК, контролируемая подпись релиза.
- [ ] Автономный канал корпоративных обновлений из доверенного каталога с проверкой подписи/версии/откатом.
- [ ] Необязательное подключение к GET-system через версионированный контракт; работа программы не зависит от доступности сервера.
- [ ] После приёмки: второй PR к GUP-Scan для удаления PDF UI и лишних ассоциаций, **с сохранением экспорта полученных сканов в PDF**.

## Запреты и требования

- Не включать GitHub Actions и не объявлять локальные/hardware тесты пройденными без запуска.
- Не устанавливать scanner workers/TWAIN/WIA в PDF-продукт.
- Не изменять оригинальные документы и выбор пользователя для `.pdf` без явного действия.
- Не выдавать статические проверки подписей, форм или картинок за криптографическую/визуальную проверку.
- Ни PR #1, ни PR с улучшениями не объединять с `main` до Windows gate и согласованной приёмки.
