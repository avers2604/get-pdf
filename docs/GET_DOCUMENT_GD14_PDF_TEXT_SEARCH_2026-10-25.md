# GD-14 — поиск PDF во вкладке «ГЭТ Документ» и обработка конфликтов GUP-2

Дата: 25.10.2026. Статус **Draft / код внесён в feature, не прошёл build/MSTest**.

## База и reuse-first

- Основание: `feature/get-document-gd13-integrated-office-return-pdf` (PR #34, затем #33 → #31). Никакой второй PDF-программы или окна не создаём.
- Для поиска текстового слоя используется **тот же PdfPig 0.1.16**, который уже указан в `src/GetPdf/GetPdf.csproj`. Он добавлен в Avalonia `GetDocument.Desktop`, без самостоятельного PDF text parser. PdfPig распространяется по Apache-2.0 (проверить список third-party notices перед выпуском).
- По умолчанию текст не индексируется на диск, не отправляется по сети, не логируется. Поиск выполняется в памяти на локальной копии/доступном SMB-файле с ограничением **128 MiB / 1000 страниц**, отменяется при закрытии вкладки или новом запросе.

## UI и фактическое поведение

- Поле поиска и «Найти» прямо в существующей PDF-вкладке; `Enter` запускает поиск. `Ctrl+F` ставит фокус на поле; `F3` и `Shift+F3` переходят по следующим/предыдущим страницам с результатами.
- Текст извлекается через `ContentOrderTextExtractor` (PdfPig), совпадения ищутся без учёта регистра (в том числе кириллица), **буквально**, без регулярных выражений.
- В интерфейсе показаны число страниц-совпадений и страница выбранного результата. Это **не подсветка глифов** и не точная геометрия, отдельные совпадения внутри одной страницы пока не выбираются.
- Для полностью отсканированных PDF без доступного текста выводится указание на необходимость OCR. OCR-процессор пока не подключён.
- Ограничения: строка 1–128 символов, обработка не более 250000 символов и 100 совпадений на страницу; проверка не полностью охваченных страниц явно отмечается. Фрагменты сокращаются до 160 символов, управляющие/направляющие Unicode-символы удаляются. Парольные/повреждённые PDF могут быть недоступны.

## Интеграция безопасного ответа GUP-2 (source-first)

- Из уже подготовленного PR #35 унаследован контракт: `HTTP 409` при конфликте версии теперь превращается в `OfficeReturnConflictException`, а не общий отказ.
- Пользователь получает отдельное объяснение необходимости открыть актуальную карточку, сравнить рабочие копии и получить новый одноразовый код. Нет автоматического retry, merge или overwrite; локальная копия не удаляется.
- Серверный 409 зависит от GUP-2 PR #163, серверная интеграция и клиентская отправка **выключены по умолчанию**, до локальной ИБ-приёмки.

## Блокирующие пункты до замены ГЭТ PDF

1. Печать PDF по драйверу, диалог печати, A4/A3, копии, двусторонняя печать; в Avalonia пока не реализовано.
2. Настоящее выделение глифов, прямоугольники подсветки, OCR, PDF формы/подписи/аннотации, объединение/разделение/изменение страниц, защита WORM — перенос с legacy WPF в новую оболочку.
3. Полноценный DOCX/XLSX/PPTX редактор и проверка roundtrip MS Office на корпоративных эталонах.
4. Серверный Collabora/ONLYOFFICE broker и AD/SSO, PKI, WOPI proof, версионирование GUP-2, журналы/ACL, реальные 2/5/10-сотрудниковые сессии.
5. Локальная сборка .NET 10, независимое code review, лицензии, security scan и подписанный установщик с откатом.

До этих проверок **legacy GetPdf.exe и пользовательские файловые ассоциации остаются неизменными**.
