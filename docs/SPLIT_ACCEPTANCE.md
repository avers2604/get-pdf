# Изоляция ГЭТ PDF от GUP Scan

## Граница приложений

ГЭТ PDF: Windows/WPF PDF viewer, continuous pages, search, print, save-as, page operation tools, annotations, OCR, local PDF text editing, scratch/diagnostics/policy. Несколько PDF одновременно открываются в независимых окнах.

GUP Scan: TWAIN x86, WIA, NAPS2 scanner workers, профили МФУ, поиск драйверов, захват страниц, исправление изображений сканера. Эти модули **не входят** в проект `GetPdf.csproj`.

## Регрессионная приёмка новых возможностей (без ложных PASS)

- [ ] `Ctrl+F` показывает поиск при закрытом редакторе; Enter и F3, результаты и подсветка синхронны.
- [ ] Смена трёх режимов просмотра не обрывает рендер и навигацию; F11/Escape корректны.
- [ ] Миниатюры при 200 страницах не растут неограниченно, память и отмена проверены в реальном WPF.
- [ ] Недавние документы: очистка списка, несуществующий путь, сетевой путь и несколькo PDF.
- [ ] Закладки: сохранение, переход, добавление, удаление и поведение после изменений файла.
- [ ] PDF outline: вложенные разделы, кириллица, отсутствие заголовков, /Dest, /GoTo, недоступные именованные ссылки, большие/циклические структуры.
- [ ] PDF /Link: внутреннее назначение, внешний /URI, /Launch, /JavaScript, сломанная ссылка; никакая внешняя команда не выполняется.
- [ ] Перемещение/удаление страницы не приводит к переходу в неправильный исходный PDF-объект; предыдущий документ не оставляет свои ссылки в новом.
- [ ] Ctrl+G: номер 1, последняя страница, 0, за диапазоном, ввод текста; Enter и обычная навигация не мешают друг другу.
- [ ] Поиск назад Shift+F3, вперёд F3, циклическая навигация, синхронизация списка совпадений.
- [ ] Сравнение: добавленная, удалённая и заменённая текстовая страница; скан без текстового слоя помечен как непроверенный.
- [ ] Предпросмотр печати содержит рамки, штампы и заметки; отмена не отправляет задание в очередь.
- [ ] Нумерация и разделение страниц: отмена, ошибки диска, существующие файлы, исходный PDF не изменён.
- [ ] qpdf: утверждённый SHA-256, отсутствие бинарника, подпись/формы, проверка текста и очистка временных файлов.
- [ ] Установщик MSI: подпись, регистрация в Open With, ярлык, обновление/удаление и совместная установка с GUP-Scan.

## Перед приёмкой

- [ ] На Windows 10/11 с .NET SDK 10: `dotnet restore src/GetPdf/GetPdf.csproj` (официальный набор пакетов).
- [ ] `dotnet build src/GetPdf/GetPdf.csproj -c Release --no-restore` без ошибок.
- [ ] `dotnet test tests/GetPdf.Tests/GetPdf.Tests.csproj -c Release`.
- [ ] Двойной клик PDF из Проводника после ручного выбора ГЭТ PDF приложением по умолчанию.
- [ ] Открыть 2–3 PDF одновременно (включая через мультивыбор и аргументы запуска); проверить независимый масштаб и закрытие.
- [ ] Проверить просмотр непрерывной лентой на PDF из 200 страниц, миниатюры, поиск кириллицы и Ctrl+P.
- [ ] Проверить печать: весь документ/диапазон, A4/A3, копии, отмену и ошибки принтера.
- [ ] Проверить «Редактирование»: операции страниц, сохранение копии, OCR, текст и шрифты, защищённый/подписанный PDF.
- [ ] Проверить временные каталоги `%LOCALAPPDATA%\GET-PDF` и `%PROGRAMDATA%\GET-PDF`; GUP-Scan остаётся нетронутым.
- [ ] Проверить инсталлятор/регистрацию ассоциаций `.pdf` без смены пользовательского выбора насильно.

**Правило:** источники сканера и его ассоциацию PDF не удаляем из GUP-Scan до успешной приёмки новой независимой сборки. Следующий отдельный PR в GUP-Scan должен удалить из него PDF UI и регистрацию .pdf после миграции пользователей.

GitHub Actions для тестов не включать. До прохождения Windows gate PR должен оставаться draft.
