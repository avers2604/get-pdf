# ГЭТ PDF — автономная ИТ-проверка обновления MSI

Для локального корпоративного канала `GetPdf` добавлен **только проверяющий**
скрипт `scripts/windows-check-offline-update.ps1`. Он не скачивает, не запускает,
не устанавливает и не удаляет программы. Используйте только каталог,
контролируемый администраторами ГЭТ (локальная папка либо внутренний защищённый SMB).

Передача внутреннего релизного пакета:
1. Выпустить MSI штатным `windows-build-msi.ps1`, проверить на Windows
   сборку, локальные тесты, реальную печать и обновление/удаление в VM.
2. Подписать MSI корпоративным сертификатом, утверждённым ИТ-службой.
3. После отдельной ручной приёмки установить `releaseApproved=true` и
   `msiInstallUpgradeRemoveValidated=true` в `release-manifest.json`.
   Эти поля — процедурный сигнал, **не** защита от подделки манифеста.
4. Скопировать подписанный MSI и манифест вместе в отдельный каталог с
   доступом на запись только у доверенной службы обновлений.

Проверка администратором на Windows:

```powershell
pwsh -File .\scripts\windows-check-offline-update.ps1 `
  -PackageDirectory 'D:\ApprovedUpdates\GetPdf-0.2.0' `
  -TrustedSignerThumbprint '40_HEX_CHARACTERS_FROM_IT_PKI'
```

Скрипт проверит SHA-256, Windows Authenticode `Valid`, точный thumbprint
подписанта, подлинные ProductName/UpgradeCode/ProductVersion таблицы
Windows Installer и запрет понижения версии. Пиннинг подписанта
отдельно от системного доверия обязателен. При недоступности CRL/OCSP
проверка может быть заблокирована; нельзя подменять `Valid` на `UnknownError`.

Проверка чистой установки в тестовой VM требует явного
`-AllowFreshInstall`.

**Инсталляция/откат не реализованы автоматически.** Администратор отдельно
запускает подписанный MSI после проверки, а перед обновлением сохраняет
предыдущий утверждённый MSI/снимок VM для отката. Ни скрипт, ни PDF-приложение
не должны изменять `UserChoice` и компоненты GUP-Scan.

**Не испытано:** COM Windows Installer, сценарии повышения версии,
отклонение подделанной подписи и реальные правила PKI/CRL. В текущей среде
не выполнялись Windows/.NET/WiX/PowerShell тесты. Статус — предварительный
ИТ-инструмент, а не готовый автoобновляющий агент.
