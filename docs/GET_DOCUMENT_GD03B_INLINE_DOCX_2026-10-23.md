# GD-03B — ограниченное редактирование DOCX внутри общей вкладки

**Назначение:** первый безопасный рабочий сценарий ввода текста непосредственно в Avalonia, без запуска второго Office окна.

- Добавлен `SimpleDocxEditor` в `GetDocument.Office` без новых NuGet пакетов.
- Вкладка обычного `.docx` показывает редактируемое поле только если DOCX содержит исключительно обычные абзацы/текстовые Run без оформления, вложенных частей, таблиц, изображений и иных структур.
- Любой сложный DOCX отклоняется для редактирования с объяснением. **Он не конвертируется в плоский текст**, исходное оформление не теряется.
- «Сохранить новую редакцию…» проверяет SHA256 загруженной версии, отклоняет изменённый источник, создаёт отдельный OOXML `.docx` в той же папке, проверяет результат, публикует через File.Move **без overwrite**. Исходник и файлы WORM не перезаписываются.
- После успеха новая редакция остаётся в той же вкладке (ID неизменен). Контракт `DocumentWorkspace.BindNewRevision` не позволяет связывать файл из другой открытой вкладки.
- Несохранённый ввод блокирует закрытие своей вкладки/окна; «Отменить правки» возвращает исходное содержимое.
- Добавлены MSTest до реализации: чистый DOCX, отклонение сложного форматирования, сохранность WORM/существующего пути, защита от устаревшего источника, лимиты и XML-символы.

## Не является готовым Word
Вариант умеет только плоские абзацы. **Жирный текст, таблицы, стили, списки, колонтитулы, ссылки, рисунки, комментарии, рецензирование и печать DOCX пока не поддержаны.** ProEdit/LibreOffice испытания по сложным форматам не закончены. XLSX и PPTX пока можно только создать, не редактировать во вкладке.

## Ограничения перед промышленным релизом
- В окружении правки отсутствует dotnet SDK: **новый C# не собирался и MSTest не запускались**.
- Нужен изолированный парсер/worker для недоверенных ZIP/OOXML: лимит 16 МиБ по сжатому размеру не защищает от ZIP bomb.
- SaveFilePicker в зависимости от платформы может создавать пустой файл заранее — проверить поведение, не допускать незаметной перезаписи.
- Доступ к SMB/ACL, кириллица, конкурентное изменение, закрытие при вводе, восстановление после аварии — обязательные локальные E2E.
- **Не сливать** Draft PR в main до сборки Windows/Linux, регрессий PDF и отдельной проверки политики файлов.
- Прямые подключения к GUP-2, ГЭТ System, сканированию, веб-версии и скрытой сетевой игре этим PR не меняются.
