# GD-31D — оформление пилотных DOCX и печать таблиц (28.10.2026)

**Статус:** исходники + тестовые сценарии, **не релиз**. Stacked на GD-31C PR #62 и GD-31A PR #60. `main` и корпоративные серверы не меняются.

## 1. Корпоративные шаблоны Word

Доработан существующий генератор `CorporateTemplateService` на `DocumentFormat.OpenXml` и `Scriban`. **Без новых зависимостей**, без внешних URL, пользовательские поля по-прежнему передаются как текст.

- Три существующих пилотных формы: **служебная записка, акт, официальное письмо**.
- Формат A4, портретный: **11906 × 16838 twips** (~210×297 мм).
- Поля: слева **1701 twips** (~30 мм), сверху/справа/снизу **1134 twips** (~20 мм).
- Заголовок по центру и полужирный, 13 pt. Основной текст — 11 pt, Arial, межстрочный множитель 1,15. Пустые строки/переносы исходного текста сохраняются отдельными абзацами.
- Официальный логотип, реквизиты, подписи, печати, утверждённые бланки и фирменные шрифты **не добавлялись**: формы остаются **пилотными**, не подменяют утверждённые локальные нормативные образцы.
- Генератор по-прежнему создаёт **новый DOCX в той же папке через staging + File.Move без перезаписи**, не меняет WORM.

## 2. Дополнительные команды ГЭТ Таблицы

Добавлены четыре строго типизированных локальных операции в `OfficeFeatureCatalog` и в whitelist встроенного `lo_editor.py`:

| ID | Пользовательское действие | UNO |
| --- | --- | --- |
| `calc-print-used-area` | «Печатать заполненную область» текущего листа | `createCursor().gotoEndOfUsedArea(True)`; `XPrintAreas.setPrintAreas` |
| `calc-clear-print-area` | «Сбросить область печати» текущего листа | `XPrintAreas.setPrintAreas(())` |
| `calc-repeat-first-row` | «Повторять первую строку» при печати | `XPrintAreas.setTitleRows`, `setPrintTitleRows(True)` |
| `calc-stop-repeat-rows` | «Отключить повтор строк» | `XPrintAreas.setPrintTitleRows(False)` |

Команды выполняются **только в Calc**, **только с доступом к редактированию** и с независимой повторной проверкой в мосте Python. Для «заполненной области» введён защитный предел **2 млн ячеек**, чтобы случайно не сформировать чрезмерный печатный документ. Печатается **область активного листа**; существующие индивидуальные параметры этого листа меняются только по явной команде сотрудника.

В фирменную панель добавлено подменю **«Печать таблицы»**. Отправка на принтер остаётся в существующем мастере ГЭТ и осуществляется через уже реализованную цепочку `Office → PDF → Print Wizard`, **не через стандартный диалог**.

**Важное поведение LibreOffice:** когда хотя бы один лист содержит явно установленную область печати, листы без такой области могут исключаться из печати. Проверять предпросмотр всего PDF прежде чем печатать книгу. Опция «Печатать заполненную область» не означает «печатать только выделение».

## 3. Новые тестовые сценарии

- `CorporateTemplateServiceTests`: формат A4 для всех трёх форм, проверка размера бумаги и полей, центровки и выделения заголовка, сохранения многострочного текста, отсутствия внешних связей и неутверждённых вложенных изображений.
- `OfficeFeatureCatalogTests`: четыре новые команды должны быть только Calc, отказывать в read-only, быть представлены в C# и Python whitelist, выполняться через реальный LibreOffice в smoke сценарии.
- На текущем этапе **статически** сверены **11/11** ID всех команд между каталогом, Python-мостом, собственным UI и тестами. Это **не** результат MSTest/компиляции.

## 4. Обязательная локальная приёмка

```powershell
dotnet restore GetDocument.slnx
dotnet build GetDocument.slnx -c Release --no-restore
dotnet test tests/GetDocument.Office.Tests/GetDocument.Office.Tests.csproj -c Release --no-restore --filter "FullyQualifiedName~CorporateTemplateServiceTests|FullyQualifiedName~OfficeFeatureCatalogTests"
.\scripts\verify-get-document-windows.ps1
```

Затем вручную: открыть шаблоны в **Microsoft Word** и сверить A4, текст и отступы; открыть XLSX с ≥2 листами и повторяющимися заголовками, проверить изменения области печати, экспорт через мастер PDF, A4/A3 и реальную печать на Windows/CUPS; проверить SMB, read-only, шаблон в закрытом контуре. Прогнать OOXML structural diff, проверить невозможность перезаписи архивного оригинала.

**Не проверено в этом сеансе:** .NET 10 build, MSTest, UI, настоящий LibreOffice, Windows/Linux, физическая печать и round-trip Office. Ни один пункт нельзя маркировать production-ready до локальной приёмки. GitHub Actions не включены.
