# ГЭТ PDF — установщик и приложение по умолчанию

С версии 0.1.2 выпуск состоит из двух файлов:

| Файл | Для кого | Что это |
|---|---|---|
| `GetPdf-0.1.2-Setup.exe` | пользователи | Мастер установки в стиле GET DS 4.1, внутри — MSI |
| `GetPdf-0.1.2-win-x64.msi` | ИТ-служба | Тот же продукт для GPO / SCCM / `msiexec /qn` |

## Сборка

Требуется Windows x64, .NET SDK 10 и WiX Toolset 5 с расширениями UI/Util (один раз на машину):

```powershell
dotnet tool install --global wix --version 5.0.2
wix extension add -g WixToolset.UI.wixext/5.0.2 WixToolset.Util.wixext/5.0.2
.\scripts\windows-build-msi.ps1
```

Скрипт выполняет restore → build → MSTest (порог 192) → чистый self-contained publish →
qpdf → `wix build` (`-culture ru-RU`) → мастер `GetPdf.Setup` с MSI внутри и пишет в `dist\release`
`GetPdf-0.1.2-Setup.exe`, `GetPdf-0.1.2-win-x64.msi` и `release-manifest.json`.

### qpdf в составе установки

С 0.1.2 qpdf ставится вместе с программой (`C:\Program Files\GET PDF\tools\qpdf`): сжатие PDF без
потерь и проверка структуры сохранённых копий работают сразу, без участия ИТ.

- Источник — официальный релиз qpdf 12.4.2 (`qpdf-12.4.2-msvc64.zip`, лицензия Apache-2.0).
  Скрипт сверяет SHA-256 архива с опубликованным в `qpdf-12.4.2.sha256`
  (`db87077e…5de25d`) и отказывается собирать при несовпадении.
- Для офлайн-сборки: `.\scripts\windows-build-msi.ps1 -QpdfZip D:\dist\qpdf-12.4.2-msvc64.zip`.
  Иначе архив скачивается один раз и кешируется в `packaging\third-party\` (вне git).
- В папку кладутся `qpdf.exe`, `qpdf30.dll`, распространяемые с qpdf библиотеки MSVC,
  `LICENSE-qpdf.txt` и `qpdf.sha256` — программа проверяет хеш `qpdf.exe` перед каждым запуском
  и скрывает команду, если файл изменён.
- Код возврата qpdf 3 («есть предупреждения») считается успешным: так qpdf отвечает на многие
  обычные PDF, в том числе сохранённые самой программой. Результат при этом проверяется отдельно
  (число страниц, текст), а строка состояния пишет «есть некритичные замечания».

### Мастер установки (GetPdf.Setup.exe)

- WPF на .NET Framework 4.8 (входит в Windows 10 1903+ и 11), поэтому мастер почти ничего не весит
  сверх MSI. Окно в стиле DS 4.1: тёмно-синяя полоса со знаком ГЭТ, шаги «Параметры → Установка → Готово»,
  кнопки 44 px, фирменный флажок и полоса прогресса.
- Сам продукт ставит Windows Installer: мастер вызывает `MsiInstallProduct` с собственным
  обработчиком прогресса (`MsiSetExternalUI`), поэтому откат, обновление и запись в «Программах»
  работают как у обычного MSI. Журнал — `%TEMP%\GetPdf-Setup-<дата>.log`.
- Находит установленную версию по UpgradeCode: «Установка» / «Обновление» (папка сохраняется) /
  «Переустановить или удалить» (та же версия) / «Установлена более новая версия».
- Если ГЭТ PDF открыт, просит закрыть его (жёлтое предупреждение DS), а не перезагружать компьютер.
- После установки, если флажок оставлен, открывает «Приложения по умолчанию» на ГЭТ PDF и запускает
  программу через Explorer — от имени пользователя, а не администратора.
- Копия MSI хранится в `C:\ProgramData\GET-PDF\Package\<версия>` для восстановления из «Программ»;
  старые версии оттуда удаляются.
- Классический мастер самого MSI тоже получил DS-оформление (`packaging\art\*.bmp`,
  генерирует `packaging\make-wixui-art.ps1`).

## Что делает установщик

- Устанавливает приложение для всех пользователей в `C:\Program Files\GET PDF` (perMachine,
  требует прав администратора) и создаёт ярлык «ГЭТ PDF» в меню «Пуск».
- Мастер на русском языке: приветствие → папка установки → установка → завершение.
- Регистрирует ГЭТ PDF как обработчик PDF, но **не меняет выбор пользователя**:
  - ProgID `GetPdf.PDF` (иконка, команда открытия);
  - `.pdf\OpenWithProgids` — пункт в «Открыть с помощью»;
  - `Applications\GetPdf.exe` (`FriendlyAppName`, `SupportedTypes`);
  - `Software\GetPdf\Capabilities` + `RegisteredApplications\GetPdf` — запись в «Параметры › Приложения › Приложения по умолчанию»;
  - `App Paths\GetPdf.exe`.
- На последней странице включён флажок «Открыть „Приложения по умолчанию“…». На Windows 11 22H2+
  он открывает страницу ГЭТ PDF (`ms-settings:defaultapps?registeredAppMachine=GetPdf`), на более
  старых версиях — общую страницу «Приложения по умолчанию».
- Иконка программы — инверсный знак ГЭТ из брендбука на корпоративном тёмно-синем
  (`src/GetPdf/Assets/get-pdf.ico`, из `get-mark-inverse.png`): читается и на светлой, и на тёмной панели задач.
- Иконка PDF-файлов отдельная: лист с загнутым углом, красная плашка «PDF» и маленький знак ГЭТ
  (`pdf-document.ico` рядом с exe, на неё ссылается ProgID).
- Новая версия ставится поверх старой (MajorUpgrade; пересборка той же версии тоже заменяет её,
  `AllowSameVersionUpgrades`). В «Программах» указана папка установки (`ARPINSTALLLOCATION`).

## Как сделать ГЭТ PDF приложением по умолчанию

Windows 10/11 защищает выбор приложения по умолчанию (`UserChoice`): установщик технически может
только зарегистрировать ГЭТ PDF и предложить выбор.

- **Пользователь:** на последней странице мастера оставить флажок → в открывшихся параметрах
  нажать строку `.pdf` → выбрать «ГЭТ PDF». Другой путь: ПКМ по PDF › «Открыть с помощью» ›
  «Выбрать другое приложение» › «ГЭТ PDF» › «Всегда».
- **ИТ-служба, для всех пользователей домена:** после установки MSI применить
  `packaging/DefaultAppAssociations.xml` через GPO «Set a default associations configuration file»
  или командой `Dism /Online /Import-DefaultAppAssociations:…` при подготовке образа.

Тихая установка для развёртывания (без мастера и без открытия параметров):

```bat
msiexec /i GetPdf-0.1.2-win-x64.msi /qn /l*v getpdf-install.log
```

Удаление: «Параметры › Приложения», повторный запуск `GetPdf-0.1.2-Setup.exe` → «Удалить ГЭТ PDF»
или `msiexec /x GetPdf-0.1.2-win-x64.msi /qn`.
Регистрация удаляется вместе с программой.

## Проверено (22.10.2026, Windows 11, 125 % DPI)

- `windows-build-msi.ps1` целиком: 181/181 тестов, MSI 66 МБ, 492 файла.
- Установка `/passive` с кодом 0. Есть файлы, ярлык «Пуск» и запись в «Приложениях»;
  все ключи реестра на месте; ГЭТ PDF появился в `OpenWithProgids` рядом с другими PDF-программами;
  текущий выбор пользователя не изменён.
- Установленная копия запускается командой, зарегистрированной для ProgID, и открывает PDF. Иконка — официальный знак.
- `ms-settings:defaultapps?registeredAppMachine=GetPdf` открывает «Приложения по умолчанию › ГЭТ PDF» с типом `.pdf`.

Не проверено: интерактивный мастер с кликами по страницам, обновление поверх предыдущей версии
(MajorUpgrade), удаление, применение `DefaultAppAssociations.xml` через GPO/DISM,
Authenticode-подпись MSI.

## Проверено (23.10.2026, мастер 0.1.2)

- `windows-build-msi.ps1` целиком: 192/192 тестов, MSI 65,8 МБ, Setup.exe 65,9 МБ.
- Реальное обновление 0.1.0 → 0.1.2 через `GetPdf-0.1.2-Setup.exe` (UAC подтвердил пользователь):
  `MainEngineThread is returning 0`, в «Программах» одна запись 0.1.2.0 с папкой установки,
  `tools\qpdf\qpdf.exe --version` = 12.4.2, копия пакета в `ProgramData\GET-PDF\Package\0.1.2`.
  После «Готово» открылись «Приложения по умолчанию» и запустилась ГЭТ PDF от обычного пользователя.
- Экраны мастера (обновление найденной 0.1.0) сняты без повышения прав (`__COMPAT_LAYER=RunAsInvoker`).

Не проверено: удаление и «Переустановить» через мастер, отмена посреди установки, установка
на чистый ПК без предыдущей версии, мастер на 150 % / 200 % DPI.

## Необязательный компонент, который ставит ИТ-служба

- **OCR:** `tessdata\rus.traineddata` и `tessdata\eng.traineddata` рядом с GetPdf.exe.
  Без них команда «Распознать текст (OCR)…» скрыта. (qpdf с 0.1.2 входит в установку.)
