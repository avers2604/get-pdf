# ГЭТ Документ 0.1.0 — первая рабочая версия (26.10.2026)

Ветка PR #39 (`feature/get-document-gd16-custom-print-wizard`). Здесь описано, что изменилось
поверх GD16 и как это проверено на Windows 11.

## Что сделано

### Word, Excel и PowerPoint — прямо во вкладке, в дизайне GET DS

Документ редактируется в самой вкладке ГЭТ Документ, а не в отдельной программе.

- **Как это устроено.** Страницы рисует встроенный LibreOffice. Его меню, панели, боковая
  панель, строка состояния и информационные плашки отключены. Все команды — на панели GET DS
  над документом.
- **Панель для Word:**
  - сохранить, отменить, повторить;
  - стиль абзаца, шрифт, размер;
  - Ж / К / Ч, выравнивание, маркированный и нумерованный списки, отступы;
  - таблица 2×2 … 5×5, изображение, разрыв страницы.
- **Панель для Excel:**
  - шрифт, Ж / К / Ч, выравнивание, перенос текста, объединение ячеек;
  - формат чисел (общий / число / денежный / процент / дата);
  - автосумма, вставка строки и столбца, удаление строк, сортировка, фильтр;
  - строка формул остаётся.
- **Панель для PowerPoint:** шрифт, Ж / К / Ч, выравнивание, списки; новый и удаление слайда,
  изображение, показ.
- **Справа во всех трёх:** масштаб, «Найти и заменить», PDF, «Копия…» (другой формат или папка),
  «Печать».
- **Состояние кнопок** приходит из LibreOffice: Ж / К / Ч, выравнивание, текущие шрифт, размер
  и стиль, доступность «Отменить» и «Повторить».
- **Несохранённые изменения** отмечаются точкой «●» в заголовке вкладки. Закрытие вкладки и
  программы спрашивает подтверждение. Кнопка «Сохранить» становится основной.
- **Ctrl+S, Ctrl+P, Ctrl+Shift+S, Ctrl+W** внутри документа перехватываются: сохраняет и печатает
  ГЭТ Документ (мастер печати ГЭТ, диалоги ГЭТ). Диалогов LibreOffice не появляется.
- **Печать и PDF** берут документ как он на экране, вместе с несохранёнными правками.
- **Технически:**
  - отдельный «оконный» LibreOffice со своим профилем `%LOCALAPPDATA%\GET-Document\libreoffice-editor`
    (светлая тема независимо от темы Windows, русский язык, без советов, отчётов о сбое и
    восстановления, макросы не выполняются);
  - мост `lo_editor.py` на Python из LibreOffice;
  - окно документа переносится во вкладку через Win32 (`SetParent`) и при переключении вкладок
    не пересоздаётся.
- **Скорость.** LibreOffice запускается заранее, через 3 с после старта программы. После этого
  документ открывается примерно за 0,3–1 с.
- **Блокировки файлов:**
  - блокировку, оставшуюся после сбоя самого редактора, программа снимает;
  - если файл открыт у коллеги, документ открывается только для чтения, изменения можно
    сохранить копией;
  - пароль и другие вопросы при открытии не вешают программу: она показывает понятную ошибку.
- **Без встраивания** (не Windows) остаются PDF-просмотр через LibreOffice и редактирование в окне LibreOffice.

### PDF как в ГЭТ PDF

Вкладка PDF использует проверенный код ГЭТ PDF (общие исходники в `GetDocument.Pdf`):

- миниатюры и непрерывная прокрутка;
- поиск с подсветкой, выделение текста, масштаб (в том числе Ctrl+колесо);
- поворот, удаление, извлечение, вставка и объединение страниц;
- штамп, нумерация «N из M», прямоугольники и заметки;
- отмена и повтор;
- «Сохранить как…» (исходный файл не перезаписывается);
- сжатие qpdf, проверка подписей, заполнение форм, сравнение;
- печать отредактированной копии.

### История и избранное

На стартовом экране есть «Избранное» и «Недавние» для всех форматов. При первом запуске
история и избранное переносятся из ГЭТ PDF.

### Дизайн GET DS 4.1

Светлая тема:

- фирменная шапка со знаком;
- плитки быстрых действий на стартовом экране;
- иконки;
- кнопки primary / ghost;
- строка состояния, которую можно прочитать.

Для экранного диктора подписаны вкладки и поля поиска.

### Установщик

- `GetDocument-0.1.0-Setup.exe`: тот же мастер GET DS, что у ГЭТ PDF, собранный с
  `-p:SetupProduct=GetDocument` (все тексты — из `src/GetPdf.Setup/Product.cs`). Внутри — MSI.
- `GetDocument-0.1.0-win-x64.msi` — для ИТ (GPO / SCCM / `msiexec /qn`).
- Установка для всех пользователей: `C:\Program Files\GET Document`, пункт в меню «Пуск».
  У ГЭТ Документ свой UpgradeCode, поэтому он ставится рядом с ГЭТ PDF.
- Внутри установки:
  - самодостаточный .NET 10;
  - процесс печати `GetDocument.PrintWindows.exe`;
  - qpdf 12.4.2;
  - собственный LibreOffice 26.2.6 в `libreoffice\`. Он урезан до русского и английского
    языков, без онлайн-обновления и без регистрации в Windows; системный LibreOffice
    не затрагивается.
- Программа регистрируется в «Открыть с помощью» и в «Приложениях по умолчанию» для PDF,
  документов, таблиц, презентаций и изображений. У типов файлов свои иконки
  (PDF / DOC / XLS / PPT). Назначает программу по умолчанию только пользователь: мастер
  открывает параметры Windows.
- Сборка: `pwsh -File scripts/windows-build-get-document.ps1` (параметры `-QpdfZip`,
  `-LibreOfficeMsi`, `-OfflineNuGetFeed`, `-SideBySideMsi`). Архивы закреплены по SHA-256.

## Проверено

- `verify-get-document-windows.ps1`: GetDocument Core 107, Office 42, Images 13, Revisions 13,
  Collaboration 69, WopiGateway 39, GetPdf 192 — все тесты прошли.
- `windows-build-get-document.ps1`: собраны `GetDocument-0.1.0-Setup.exe` и MSI (по 356 МБ);
  урезанный LibreOffice — 659 МБ, `soffice --version` = 26.2.6.
- Встроенный редактор (`LibreOfficeEditorTests`, на урезанном комплекте):
  - открыть, ввести текст, применить жирный;
  - признак изменений;
  - Ctrl+S перехвачен;
  - PDF, копия в ODT, сохранение оригинала;
  - устаревшая собственная блокировка снимается, чужая — только чтение.
- В приложении:
  - Word, Excel и PowerPoint во вкладках без меню, панелей и плашек LibreOffice;
  - «Ж» с панели применяется, состояние кнопок синхронно;
  - ввод в ячейку после переключения вкладок;
  - «Сохранить» записывает файл и снимает «●»;
  - «Печать» открывает мастер ГЭТ с живым PDF;
  - при выходе LibreOffice закрывается и снимает блокировки.
- Тесты конвертации LibreOffice на урезанном комплекте (`GETDOC_SOFFICE`) — 3/3. Первый прогон
  с новым профилем один раз не уложился во время: холодный старт занимает около 2 минут.
- Мастер (без повышения прав): тексты ГЭТ Документ, папка `C:\Program Files\GET Document`,
  встроенный пакет найден, элементы помещаются в окно.
- Офисные предпросмотры (раньше, на полном LibreOffice): DOCX 2,7 с, XLSX 1,3 с,
  обновление после сохранения 2,1 с.
- PDF-вкладка через UI Automation:
  - штамп и нумерация (результат проверен PdfPig);
  - поворот, удаление, отмена и повтор;
  - поиск;
  - печать отредактированной копии;
  - сжатие qpdf 167 → 71 КБ;
  - подписи, сравнение, избранное.

## Не проверено

- Настоящая установка, обновление и удаление через мастер (отложено пользователем).
- Набор текста реальной клавиатурой и мышью (проверено сообщениями Windows в окно документа
  и через UI Automation — пользователь работал за компьютером).

- Физическая печать Office-документов на принтерах ГУП.
- Удаление и обновление поверх установленной версии через мастер.
- Работа на ПК без установленного Microsoft Office (шрифты Calibri / Cambria заменяются
  метрически совместимыми Carlito / Caladea из LibreOffice).
