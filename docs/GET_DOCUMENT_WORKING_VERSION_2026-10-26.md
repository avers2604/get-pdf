# ГЭТ Документ 0.1.0 — первая рабочая версия (26.10.2026)

Ветка PR #39 (`feature/get-document-gd16-custom-print-wizard`). Здесь описано, что изменилось
поверх GD16 и как это проверено на Windows 11.

## Что сделано

### Office-документы через LibreOffice (локально)

- Word, Excel и PowerPoint (`.docx .doc .odt .rtf`, `.xlsx .xls .ods .csv`, `.pptx .ppt .odp`)
  показываются так, как их увидит печать: LibreOffice конвертирует документ в PDF, вкладка
  показывает этот PDF. Раньше для них был упрощённый текстовый или табличный просмотр.
- Первый запуск LibreOffice занимает 25–30 с, поэтому через 3 с после старта программы
  запускается фоновый «тёплый» экземпляр. Он работает через UNO-мост (`lo_bridge.py` на Python
  из LibreOffice), и предпросмотр открывается за 1–3 с. Если мост недоступен, конвертация
  выполняется через командную строку, а при коде 81 (перезапуск профиля) — повторяется.
- «Редактировать» открывает документ в LibreOffice Writer / Calc / Impress со всем
  форматированием. После сохранения предпросмотр во вкладке обновляется сам (около 2 с).
- «Сохранить как PDF…» и печать идут из того же PDF, что виден на экране.
- Готовые предпросмотры кешируются в `%LOCALAPPDATA%\GET-Document\previews`
  (ключ — путь, размер и время изменения файла).

### PDF как в ГЭТ PDF

Вкладка PDF использует проверенный код ГЭТ PDF (общие исходники в `GetDocument.Pdf`):

- миниатюры и непрерывная прокрутка;
- поиск с подсветкой, выделение текста, масштаб (в том числе Ctrl+колесо);
- поворот, удаление, извлечение, вставка и объединение страниц;
- штамп, нумерация «N из M», прямоугольники и заметки;
- отмена и повтор;
- «Сохранить как…» (исходный файл не перезаписывается);
- сжатие qpdf, проверка подписей, заполнение форм, сравнение;
- печать отредактированной копии.

### История и избранное

На стартовом экране есть «Избранное» и «Недавние» для всех форматов. При первом запуске
история и избранное переносятся из ГЭТ PDF.

### Дизайн GET DS 4.1

Светлая тема:

- фирменная шапка со знаком;
- плитки быстрых действий на стартовом экране;
- иконки;
- кнопки primary / ghost;
- строка состояния, которую можно прочитать.

Для экранного диктора подписаны вкладки и поля поиска.

### Установщик

- `GetDocument-0.1.0-Setup.exe`: тот же мастер GET DS, что у ГЭТ PDF, собранный с
  `-p:SetupProduct=GetDocument` (все тексты — из `src/GetPdf.Setup/Product.cs`). Внутри — MSI.
- `GetDocument-0.1.0-win-x64.msi` — для ИТ (GPO / SCCM / `msiexec /qn`).
- Установка для всех пользователей: `C:\Program Files\GET Document`, пункт в меню «Пуск».
  У ГЭТ Документ свой UpgradeCode, поэтому он ставится рядом с ГЭТ PDF.
- Внутри установки:
  - самодостаточный .NET 10;
  - процесс печати `GetDocument.PrintWindows.exe`;
  - qpdf 12.4.2;
  - собственный LibreOffice 26.2.6 в `libreoffice\`. Он урезан до русского и английского
    языков, без онлайн-обновления и без регистрации в Windows; системный LibreOffice
    не затрагивается.
- Программа регистрируется в «Открыть с помощью» и в «Приложениях по умолчанию» для PDF,
  документов, таблиц, презентаций и изображений. У типов файлов свои иконки
  (PDF / DOC / XLS / PPT). Назначает программу по умолчанию только пользователь: мастер
  открывает параметры Windows.
- Сборка: `pwsh -File scripts/windows-build-get-document.ps1` (параметры `-QpdfZip`,
  `-LibreOfficeMsi`, `-OfflineNuGetFeed`, `-SideBySideMsi`). Архивы закреплены по SHA-256.

## Проверено

- `verify-get-document-windows.ps1`: GetDocument Core 107, Office 38, Images 13, Revisions 13,
  Collaboration 69, WopiGateway 39, GetPdf 192 — все тесты прошли.
- `windows-build-get-document.ps1`: собраны `GetDocument-0.1.0-Setup.exe` и MSI (по 356 МБ);
  урезанный LibreOffice — 659 МБ, `soffice --version` = 26.2.6.
- Тесты конвертации LibreOffice на урезанном комплекте (`GETDOC_SOFFICE`) — 3/3. Первый прогон
  с новым профилем один раз не уложился во время: холодный старт занимает около 2 минут.
- Мастер (без повышения прав): тексты ГЭТ Документ, папка `C:\Program Files\GET Document`,
  встроенный пакет найден, элементы помещаются в окно.
- Офисные предпросмотры (раньше, на полном LibreOffice): DOCX 2,7 с, XLSX 1,3 с,
  обновление после сохранения 2,1 с.
- PDF-вкладка через UI Automation:
  - штамп и нумерация (результат проверен PdfPig);
  - поворот, удаление, отмена и повтор;
  - поиск;
  - печать отредактированной копии;
  - сжатие qpdf 167 → 71 КБ;
  - подписи, сравнение, избранное.

## Не проверено

- Настоящая установка, обновление и удаление через мастер (отложено пользователем).
- Редактирование Office-документов пока открывается в отдельном окне LibreOffice — следующий шаг:
  встроить редактор во вкладку с панелью GET DS.

- Физическая печать Office-документов на принтерах ГУП.
- Удаление и обновление поверх установленной версии через мастер.
- Работа на ПК без установленного Microsoft Office (шрифты Calibri / Cambria заменяются
  метрически совместимыми Carlito / Caladea из LibreOffice).
