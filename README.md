# ГЭТ PDF (Get PDF)

Отдельное локальное Windows-приложение для работы с PDF в СПб ГУП «Горэлектротранс». Исходная PDF-подсистема перенесена из [GUP-Scan](https://github.com/avers2604/GUP-Scan). **Сканирование, TWAIN/WIA, обнаружение сканеров и драйверов сюда не входят.** Исходный репозиторий сканирования пока сохраняется без разрушительных изменений.

## Возможности

- Просмотр PDF с непрерывной прокруткой, миниатюрами, поиском, масштабом и клавиатурной навигацией.
- Несколько PDF одновременно: каждый документ открывается в отдельном окне приложения, без потери несохранённых изменений.
- Печать PDF по Ctrl+P и кнопке «Печать».
- По кнопке «Редактирование»: страницы, объединение и извлечение, разметка, OCR и изменение текста в поддерживаемых документах.
- Локальные черновики и атомарная запись выходного PDF, без сетевого сервиса.
- Независимые настройки и сеансы в каталогах GET-PDF, без пересечения с GUP-Scan.

## Сборка и тесты (Windows/.NET 10)

```powershell
dotnet restore .\src\GetPdf\GetPdf.csproj
dotnet build .\src\GetPdf\GetPdf.csproj -c Release --no-restore
dotnet test .\tests\GetPdf.Tests\GetPdf.Tests.csproj -c Release
dotnet run --project .\src\GetPdf\GetPdf.csproj -- "C:\\Documents\\document.pdf"
```

**Статус проверки:** исходные файлы перенесены через GitHub; полноценный `dotnet build/test`, запуск WPF и печать на принтере требуют Windows/.NET и пока не подтверждены. До релиза провести локальные тесты и проверить PDF-движок, OCR, шрифты и печать. GitHub Actions для тестов не используется.

## Разделение

`GUP-Scan` должен стать отдельной программой **сканирования**; его PDF-функции и ассоциацию `.pdf` можно удалять лишь после успешной приёмки этой независимой сборки. Ассоциацию Windows не менять без выбора пользователя.
